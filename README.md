# BIOROCCO – Plateforme E-commerce de Produits Biologiques

BIOROCCO est une application web e-commerce dédiée à la vente de produits biologiques et naturels marocains.  
Le projet vise à offrir une expérience utilisateur moderne et sécurisée tout en fournissant aux administrateurs des outils complets de gestion.

##  Technologies utilisées
- **Backend** : ASP.NET Web Forms (.NET Framework 4.7.2)
- **Langage** : C#
- **Base de données** : SQL Server
- **Frontend** : Bootstrap 5, Tailwind CSS
- **JavaScript** : jQuery, AJAX
- **Déploiement** : Microsoft Azure (App Service & Azure SQL)

##  Fonctionnalités principales
- Catalogue de produits avec recherche et filtres avancés
- Gestion du panier et des commandes
- Suivi des statuts de commande
- Gestion des stocks en temps réel
- Interface d’administration (produits, commandes, utilisateurs)
- Authentification sécurisée et contrôle des accès
