Ce dossier contient les images des produits.

Les images doivent être nommées selon le nom stocké dans la base de données (table ProductImages, colonne ImageUrl).

Exemples :
- huile-olive-1.jpg
- huile-bio-1.jpg
- miel-thym-1.jpg
- etc.

Si une image n'existe pas, un placeholder sera affiché automatiquement.
